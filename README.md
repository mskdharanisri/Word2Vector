WORD2VECTOR: Word Embeddings from Scratch
Overview
This project demonstrates the implementation of word vectorization (Word2Vec) from scratch using Python. Word2Vec is a popular method in NLP to represent words as vectors in a high-dimensional space, capturing semantic relationships.

Features
Preprocessing raw text data
Creating a vocabulary of unique words
Mapping words to integers for efficient computation
Generating vector embeddings for words using basic Python and TensorFlow libraries
Requirements
To run this project, you'll need the following:

Python 3.7 or above
TensorFlow
NumPy
